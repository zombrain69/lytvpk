# 模型面数检测

“模型面数检测”用于扫描 Mod 中模型资源的顶点数和三角形数量。

## 作用

高面数模型可能导致游戏卡顿、加载慢或显存压力变大。这个工具可以帮助你找出资源占用较高的 Mod。

## 检测范围

工具会读取启用和创意工坊 Mod 内的模型，统计 LOD0 的：

- 顶点数。
- 三角形数量。

LOD0 通常是最高细节模型，因此能反映模型资源的大致复杂度。

## 使用步骤

1. 打开“工具箱”。
2. 点击“Mod 模型面数检测”。
3. 等待扫描完成。
4. 查看结果中面数较高的 Mod 和模型路径。

## 在结果里搜索

结果上方的搜索框和 Mod 列表、压缩包管理用的是**同一套语法**，三个视图
（Mod 汇总 / 模型排行 / Strip Group 排行）都会按它过滤：

| 写法 | 含义 |
| --- | --- |
| `ak47` | 普通词，多个词表示"都要命中"，字符按顺序出现即可 |
| `models weapons` | 两个词可以分别命中不同字段（标题 / 文件名 / 路径 / 模型 `.mdl`、`.vtx`、`.vvd` 路径） |
| `-katana` | 排除命中的 Mod |
| `tag:无模型` | 只看没检测到模型的条目（还有 `有模型` / `估算`） |
| `tag:有模型 -tag:估算` | 有模型、且三角形数不是估算值 |
| `re:\.mdl$` | 正则匹配；写错了会直接提示「正则表达式无效」 |

命中的片段会在 Mod 名或模型路径里高亮，右侧显示 `匹配 1 / 3 个 Mod`；
搜索框旁的 **`?`** 是这份语法的说明书（和 Mod 列表同一份）。

键盘也能选结果：`↑` / `↓` 移动光标（焦点留在搜索框）、`Enter` 展开 / 收起当前行、`Esc` 清空检索；
光标位置显示在计数后面（例如 `第 1 / 3 个结果（Enter 展开 / 收起）`），当前行会自动滚进可视区。

## 结果怎么用

如果某个角色、武器或感染者替换包特别卡，可以优先检查它的模型统计。

处理方式可以是：

- 禁用高面数 Mod。
- 替换为更轻量的版本。
- 只在单人或低人数场景启用。

## 注意事项

该功能标记为 Beta，统计结果适合辅助判断，不代表一定会导致卡顿。
