# VPK 内容预览

「VPK 内容预览」让你**不解包**直接看到 VPK 里装了什么：左边是全部条目，右边是就地预览。
想确认「这个包到底是替换了武器、贴图还是脚本」时，不用再解包翻目录。

## 打开方式

- 工具箱 →「VPK 内容预览」→「选择 VPK 预览」；
- 如果 Mod 列表里只勾选了**一个** VPK，直接点工具按钮就用它（勾选多个时会提示）。

## 支持预览的类型

| 类型 | 扩展名 | 说明 |
| --- | --- | --- |
| 文本 / KeyValues | `.txt` `.cfg` `.vmt` `.vdf` `.nut` `.lua` `.res` `.json` `.xml` … | 按游戏文件编码解码（GBK / UTF-8 等），单条最大 256KB |
| 图片 | `.jpg` `.png` `.gif` `.bmp` | 直接显示，单条最大 8MB |
| VTF 贴图 | `.vtf` | 转成 PNG 显示（支持 DXT1 / DXT3 / DXT5 与常见未压缩格式） |
| 其它 | `.mdl` `.bsp` 等 | 只显示大小与说明；需要看内容请用「VPK 解包」取出后再看 |

## 说明

- 预览是**只读**的：不会修改 VPK，也不会写入缓存；
- 贴图预览显示的是**最高 mipmap 的第一帧**（多帧贴图不逐帧播放）；
- 超过体积上限的条目会提示"已跳过预览"，而不是把界面卡住。
