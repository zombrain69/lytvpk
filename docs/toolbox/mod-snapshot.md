# Mod 快照

「Mod 快照」用于保存**某一时刻的启用状态与加载顺序**，或制作一份**可以恢复文件内容的完整备份**。
适合在批量启用/禁用、整理文件、更新 Mod、删除文件之前留下一个可整体回滚的状态。

快照只保存在本机（配置目录的 `snapshots` 下），不会上传到任何地方。

## 两种类型

| 类型 | 记录内容 | 特点 | 适用场景 |
| --- | --- | --- | --- |
| 文件名快照 | `addonlist.txt`（开关 + 顺序）与 Mod 清单（名称、位置、大小） | 创建快、占用极小 | 批量启用/禁用、临时调整前 |
| 完整备份 | 上面的内容 + `addons` 根目录里的 VPK 与同名图片/`.meta` 的副本 | 可以恢复文件内容，占用更大、耗时长 | 更新、删除、重命名、集中整理前 |

workshop 目录里的 Mod 只记录启停状态、不复制文件（它们由 Steam 管理）。

## 创建快照

1. 打开「工具箱」→「Mod 快照」→「打开快照工具」；
2. 填一个容易识别的名称（例如「整理前」「写实包」）；
3. 选择类型：
   - **文件名快照（快）**：只记状态；
   - **完整备份（含文件）**：会复制 VPK 与同名图片/`.meta`（会先弹一次确认）；
4. 点「创建快照」。

## 恢复快照

1. 在快照列表点「恢复预览」——这一步**只读**，不会改动任何文件；
2. 检查「恢复计划」里逐项的标记：

| 标记 | 含义 |
| --- | --- |
| 启用 | 文件在 `disabled` 里，会被移回根目录 |
| 禁用 | 快照之后新增的 Mod（或快照时是禁用的），会被移到 `disabled` |
| 补回 | 快照是完整备份，且文件已丢失 → 从快照恢复文件 |
| 覆盖 | 文件还在但大小与快照不同 → 用快照内容覆盖 |
| 跳过 | 已经与快照一致 |
| 缺失 | 快照里有记录，但磁盘上既没有文件也没有备份内容 |

3. 点「确认并执行恢复」。执行前会自动把当前的 `addonlist.txt` 备份到「历史备份」里
   （类型 `before-snapshot-restore`），执行后 Mod 文件与 `addonlist.txt` 一起回到快照状态。

## 重要说明

- 恢复会把当前 Mod 调整回快照状态，因此**快照之后新增的 Mod 会被移到 `disabled`**；
- 完整备份用的是"文件大小相同即视为一致"的判定（不做全量哈希：大 VPK 哈希代价过高），
  如果文件内容被改过但大小恰好相同，会被判为"跳过"；
- 删除快照会把快照目录移入回收站（不可用时退回 `.removed` 目录），**不会**影响任何 Mod 文件；
- 沙箱只读模式下（CUA 调试）恢复会被拒绝，与其它写操作一致。
