# 压缩包管理

“压缩包管理”用来在不解压的前提下**看穿**一堆压缩包：递归扫描你指定的目录，
列出每个包里的文件树、识别其中的 VPK，并和当前 `addons` 里已经装好的 Mod 对比，
告诉你哪些是**待导入**、哪些**已经有了**、哪些**需要密码**或**读不出来**。

入口：**工具箱 → 通用工具 → 压缩包管理 → 选择目录**。

## 支持的格式与扫描方式

- 格式：**ZIP / RAR / 7Z / TAR**（含常见的 `.tar.gz` 变体）。
- 递归扫描所选目录下的所有包；**内容只在内存里读取，不会解压到磁盘**，也不会改动压缩包本身。
- 每个包会给出：内部条目数、包含的 VPK 数、以及和当前库的匹配状态。

## 界面上有什么

| 元素 | 作用 |
| --- | --- |
| 搜索框 + `?` | 与 Mod 列表**同一套语法**：多词"且"匹配、`-词` 排除、`re:` 正则、`"精确短语"`；`tag:` 落在包状态上（密码 / 错误 / 已有 / 待导入）。`?` 打开语法说明书 |
| 排序 | 名称 A-Z / Z-A、状态、大小从大到小 / 从小到大 |
| 状态筛选 | 全部状态 / 已有 Mod / 待导入 / 需要密码 / 读取失败 |
| 全选 · 取消全选 | 对当前筛选结果生效 |
| 移动已选 (N) | 把选中的**压缩包文件**移到目标目录（只检查压缩包自身重名，不处理图片/`.meta` 伴随文件） |
| 刷新全部 | 重新扫描（外部改动过目录时用） |
| 展开包 | 看文件树与 VPK 信息（`N 项 / M 个 VPK`），点条目可以定位 |

## 加密压缩包

- 读取失败的加密包会标成**需要密码**，可以在行内输入密码重试，只重扫这一个包。
- **密码只用于本次扫描，不写进设置、不落盘**；关掉窗口就没了。

## 怎么用（典型流程）

1. 把下载下来的整包资源放进一个目录（例如 `D:\L4D2-Downloads`）。
2. 工具箱 → 压缩包管理 → 选择该目录，等扫描完成。
3. 用 `状态筛选 → 待导入` 或直接搜 `tag:待导入`，只留下还没装过的包。
4. 展开感兴趣的包，确认里面的 VPK 是你想要的（避免整包塞进一堆重复内容）。
5. 需要整理时用「移动已选」把选中的包归到另一个目录；确认没问题再按常规流程导入 Mod。

## 常见问题

### 为什么某个包一直显示"读取失败"？

先确认它的扩展名和真实格式是否一致（把 ZIP 改名成 `.vpk`、或下载到一半的包都会失败）。
如果它确实加密，界面会标成"需要密码"，输入正确密码后即可正常读取。

### "已有 Mod"是怎么判断的？

按 VPK 的匹配结果判断：只把 `addons` 根目录、`workshop`、`disabled` 三处**受管位置**里同名同状态的 VPK
算作"已有"，其它子目录（你自己手放的内容）不会让包被误判成"已导入"。

### 它会把压缩包解压出来吗？

不会。查看文件树与 VPK 信息都是只读的；只有你主动用「移动已选」或在系统里打开包，才会动文件。
