# autoexec.cfg 编辑器

“autoexec.cfg 编辑器”用来安全地查看和修改游戏启动时读取的 `cfg/autoexec.cfg`：
**逐行分析你写了哪些控制台命令、它们是什么、有什么风险**，并且保存时保留原文件的编码、BOM 与换行格式。

入口：**工具箱 → 游戏配置 → autoexec.cfg 编辑器**。

## 它能做什么

- **编辑内容**：直接改文本；窗口右下角可以拖动调整大小。
- **逐行分析**：识别每一行的第一个命令 token，注释与空行会被忽略；未知命令**不会**被隐藏，
  而是标成「未知指令」并提示"可能来自插件或 Mod，建议确认来源后再保存"。
- **命令说明（点击插入）**：内置一份 L4D2 / Source 控制台命令说明（命令、作用域、风险、来源），
  还包含 L4N 插件命令；在搜索框里输入命令名或中文含义就能找到，点一下插入到编辑区。
- **风险提示**：说明里带风险等级，例如 `exec` 标为「中：会继续执行被引用文件」，
  `bind` / `alias` / `fps_max` 这类标为低风险。
- **重新读取 / 打开文件位置**：改之前想对照磁盘上的当前内容，或想直接在资源管理器里定位文件。

## 怎么用

1. 先在「MOD 管理」里选好 `addons` 目录——编辑器读写的是**这个目录对应游戏**的 `left4dead2/cfg/autoexec.cfg`。
2. 打开工具，看顶部状态：**文件存在** / **文件不存在，将在保存时创建**。
3. 在编辑区写你的命令；用「命令说明」搜索并点击插入，避免拼错。
4. 看下方的分析面板：每一行的命令、含义与风险；出现「未知指令」时先确认它来自哪个插件。
5. 点保存。保存后提示「已保存 autoexec.cfg（编码与换行格式已保留）」。

## 安全边界（重要）

- **只写回文件，不在本程序里执行任何命令**——它不会启动游戏、也不会替你把命令跑一遍。
- 保存时**保留原文件的编码（GBK / UTF-8 / UTF-16 等）、BOM 与换行格式**，并在写入前留备份，
  避免"用编辑器改一下就让游戏读不出来"。
- 文件不存在时保存会创建它；创建出来的编码与换行按同目录已有配置的惯例处理。

## 常见问题

### 分析里出现我不认识的命令？

大概率是某个插件（例如 L4N 系列）注册的命令。说明列表里会标注来源（`L4D2 Console commands` / `Source 引擎` /
插件包）；确实来自你不认识的 Mod 时，先删掉那行再保存。

### 改了没生效？

`autoexec.cfg` 是**游戏启动时**读取的：改完要重启 L4D2。另外确认你改的是当前选中目录对应游戏的 cfg，
而不是另一个盘上的第二份安装。

### 想恢复改动？

保存前的备份会放在配置目录的备份区；也可以用「打开文件位置」找到文件手工回退。
