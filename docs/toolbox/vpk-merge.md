# 合并为整合包

把当前勾选的多个 Mod **合并成一个 VPK**（导出整合包），适合"只想往游戏里放一个文件"或对抗模式的场景。

## 用法

1. 在 Mod 列表里勾选**两个以上**的 VPK；
2. 工具箱 →「合并为整合包」→「合并选中的 Mod」；
3. 选择保存位置（默认 `merged_addon.vpk`）；
4. 确认后等待完成，通知里会给出条目数与覆盖数。

## 规则与边界

- **顺序 = 你看到的列表顺序**：后一个包的同名文件覆盖前一个（与"后加载覆盖"的直觉一致）；
- 合并只是**复制导出**：
  - 不会改动原 Mod 文件；
  - 不会改动 `addonlist.txt`、优先级分层或冲突分析结果；
  - 合并结果**不参与**本程序的 Mod 管理，想用它需要你自己在游戏里启用它；
- 合并会把原本"两个 Mod 各自带同名文件"的重叠固化进一个包——这正是要避免冲突时的做法，
  但也意味着**冲突从此不可见**，请按需使用。
