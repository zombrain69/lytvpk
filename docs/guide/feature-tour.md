# 全功能地图（能做什么 · 去哪儿点 · 怎么开始）

这一页把 LytVPK Community Fork **所有能做的事**按界面位置列出来：每一行都写清
**入口**（哪个页面、哪个按钮）和**怎么开始**，需要展开的细节点链接看专门页面。

> 找按钮的最快方式：按 `Ctrl + K` 打开**命令面板**输入关键词；按 `?` 看**快捷键总览**。

## 一、页面地图

| 页面（左侧导航） | 用来做什么 |
| --- | --- |
| **MOD 管理** | 列表 / 卡片管理本地与工坊 Mod：启用禁用、游戏内开关、标签、筛选、排序、批量操作、加载顺序、策略组 |
| **创意工坊** | 浏览、搜索、看详情与翻译、稍后再看 |
| **下载与解析** | 解析工坊链接 / 合集 / 直链下载，管理下载任务 |
| **收藏服务器** | 服务器收藏与状态查询、连接、服务器面板（地图 / 上传 / RCON / 难度 / 热重载） |
| **工具箱** | 8 件排查与维护工具（冲突、体检、模型、打包解包、喷漆、mdmp、autoexec、压缩包） |
| **设置** | 网络设置 / 界面设置 / 工坊设置 / 游戏配置 四个面板 |
| **使用说明** | 打开文档站 |
| **关于** | 版本、检查更新、许可与致谢、崩溃报告入口 |

窗口体系：列表页顶部是**工具栏**；勾选 Mod 后底部出现**批量操作栏**；
复杂管理窗口（策略组管理、加载顺序、冲突、详情、体检…）都支持**浮动 / 拖动 / 拉伸 / 点外部关闭**。

## 二、MOD 管理页：工具栏逐个说

| 按钮 | 作用 | 怎么用 |
| --- | --- | --- |
| 选择 addons 目录 | 切换受管目录，支持多目录历史 | 第一次用先选对 `left4dead2\addons`；之后从下拉里快速切换 |
| 加载顺序 | 打开加载顺序窗口（排序、分层、约束） | 选中 Mod → 打开 → 填「优先级分层（可选）」→ **按分层应用** |
| 上传 | 从磁盘选文件导入到当前目录 | 点开局选择框选 VPK / 压缩包；也可直接把文件**拖进窗口** |
| 全部分组 | 建组、分组建议、策略组管理、按分组筛选 | 点开下拉：上半部分是动作，下半部分是组列表（可多选筛选） |
| 优先级 # + 定位 | 按 `addonlist.txt` 里的优先级编号找 Mod | 输入编号 → 定位（任何排序方式下都能找到） |
| 刷新 | 重新扫描目录 | 外部新增/删除文件后点一下 |
| 重置筛选 | 清空搜索与筛选条件 | 一键回到全部 |
| 冲突分析 | 开关列表冲突角标 | 打开后每行显示冲突角标，点角标看覆盖关系 |
| 对比范围 | 选择冲突分析的对比范围与条件组合 | 大库只想看某个范围时用 |
| 轮换已关闭 / 已开启 | 随机轮换开关 | 打开后按设置随机启用一组（配合角色/武器轮换配置） |
| 排序菜单 | 名称 / 日期 / 大小 / 模型复杂度 / 加载顺序 / **优先级排序（分层优先，其次加载顺序）** | 默认就是这一项 |
| 搜索框 + `?` | 统一语法搜索 + 语法说明书 | 支持多词、`-排除`、`tag:`、`re:`、`"短语"` |
| 显示隐藏 | 是否显示隐藏文件 | 隐藏文件在名称里带标记，可用于"临时不用但不想删"的 Mod |

## 三、MOD 管理页：列表 / 卡片上的操作

**行内按钮**：详情 · 游戏内开关 · 启用 / 禁用 · 更多操作（`⋯`）。

**`⋯` 更多操作**：详情 · 启用 / 禁用 · 调整加载顺序 · 复制到 addons · 转移至根目录（工坊件） · 跳转工坊 ·
分享物品 · 设置标签 · 加入策略组… / 从策略组移出… / 移动到其它策略组… · 上传服务器（有面板时） · 重命名 ·
打开位置 · 隐藏 / 取消隐藏 · 解包 · VPK 完整性检测 · 删除。

**勾选多个后的底部批量栏**

| 按钮 | 说明 |
| --- | --- |
| 全选 / 取消全选 | 对当前筛选结果生效 |
| 游戏内启用 / 游戏内关闭 | 只改 `addonlist.txt` 的 0/1，不动文件（`disabled` 目录里的 Mod 会被拦下并说明原因） |
| 批量启用 / 批量禁用 | 在 `addons` 与 `disabled` 之间搬文件 |
| 批量禁用 ▾ | 还可以「禁用所有mod」「禁用所有人物mod」「禁用所有武器mod」 |
| 更多操作 ▾ | 批量隐藏 / 批量取消隐藏 · 设置标签 · 分享物品 · 上传服务器 · 导出ZIP · 转移至根目录 · 移动文件 · 批量删除 |
| 选择手势 | 单击单选、`Ctrl` 点击多选、`Shift` 点击范围、拖拽**框选**（可在设置里开关） |

**单个 Mod 详情窗口**里还能看到：预览图、VPK 信息（标题/作者/版本/描述/链接）、地图信息、
基本信息、**主体识别**、标签与详细标签、**该 Mod 的冲突忽略文件**编辑器。

## 四、加载顺序与优先级

入口：工具栏 **加载顺序**。窗口里能改「新序号」、上移/下移一位、设置**优先级分层（可选）**、
配置「必须在前 / 必须在后」约束、预览完整顺序，最后点 **按分层应用** 才会写回 `addonlist.txt`。

要点：数值越小越先加载；分层是"意图 + 判定 + 排序"，`addonlist.txt` 顺序仍是游戏侧唯一权威；
未设置分层时行为与以前完全一致（黄金回归测试守着）。

详见 [MOD 管理 → 加载顺序](/features/mod-management) 与 [本 Fork 新增功能](/guide/whats-new)。

## 五、策略组与分组建议

| 想做的事 | 入口 |
| --- | --- |
| 把选中的 Mod 建成一组 | 工具栏 **全部分组** → 「用选中的 Mod 建组」 |
| 修改策略 / 权重 / 层级 / 拖放 / 批量 / 展开成员 | 工具栏 **全部分组** → 「策略组管理…」 |
| 按组筛选列表 | 工具栏 **全部分组** → 下半部分勾选组（筛选顺序按组权重，子组跟随父组） |
| 推导可能同组的 Mod / 交给大模型分析 | 工具栏 **全部分组** → 「分组建议」 |

组内策略：全部开启 / 全部关闭 / 互斥单选 / 随机单选，应用前做**可满足性预检**；
组权重沿祖先链累加、跨链取 `min`，与单 Mod 分层合成同一个**有效分层**。

详见 [策略组与分组建议](/features/group-suggestion-import) 与 [本 Fork 新增功能](/guide/whats-new)。

## 六、标签体系

- **自动标签**：扫描时按 VPK 内部路径与文件名给出一级/二级标签（武器、角色、声音、脚本、贴图、地图…）。
- **手工标签**：行内 `⋯` → 「设置标签」；多选后「更多操作 → 设置标签」。
- **工坊官方标签**：设置 → 工坊设置 → 「抓取工坊官方标签与统计」写进 `.meta` 的 `steam_tags`，与自己的标签分开存。
- **标签 × 分组互补**：标签已经能表达的类型（例如"全是替换 sg552 的枪"）不必再建组；
  外部智能体在建议文件里一起产出的标签会写回标签体系，没产出时退回自动规则。

## 七、冲突系统

| 能力 | 入口 |
| --- | --- |
| 列表冲突角标（实时） | 工具栏 **冲突分析** 开关 |
| 对比范围与条件组合 | 工具栏 **对比范围** |
| 全量冲突检测 | 工具箱 → **Mod 冲突检测** |
| 全局忽略清单（内置 ∪ 全局 ∪ 单 Mod） | 设置 → 游戏配置 → **Mod 冲突分析**；单 Mod 在「详情」里编辑 |
| 覆盖关系与严重程度 | 冲突弹窗（同一套搜索语法，可按严重度/关键字过滤） |

冲突只在**同一有效分层**内判为真冲突，其余按覆盖展示；状态变化后会自动失效并按需重算。

详见 [Mod 冲突检测](/toolbox/conflict-check)。

## 八、排查与体检

| 工具 | 入口 | 用途 |
| --- | --- | --- |
| Mod 体检 | 设置 → 游戏配置 → **Mod 体检** → 「开始体检」 | 比对开关记录与磁盘：缺文件、重复条目、损坏 VPK、依赖问题、工坊记录异常…可一键修的带「修复」按钮 |
| 问题 Mod 查找 | 工具箱 → **问题 Mod 查找** | 二分法逐轮缩小"是哪个 Mod 导致崩溃 / 进不去图" |
| Mod 冲突检测 | 工具箱 → **Mod 冲突检测** | 全量覆盖关系扫描 |
| 模型面数检测 | 工具箱 → **Mod 模型面数检测（Beta）** | LOD0 顶点数 / 三角面数排行 |
| 崩溃转储查看器 | 工具箱 → **崩溃转储查看器** | 打开 `.mdmp` / `.dmp` 看异常、线程、模块 |
| 自身崩溃报告 | 关于 → 崩溃报告 | 应用自己崩过会留下带版本与日志尾部的记录 |

体检报告支持统一检索与导出 Markdown。详见 [Mod 体检](/toolbox/mod-health-check)。

## 九、启用方案与 Mod 依赖

- **启用方案**：设置 → 游戏配置 → **启用方案**。把"哪些开 / 哪些关 + 分层"存成一套方案，
  之后一键切回；支持捕获（可含自动化信息）、应用、导出、导入。
- **Mod 依赖**：设置 → 游戏配置 → **Mod 依赖**。声明"开 A 必须先开 B"；
  体检会报出未开启的依赖并支持一键启用，依赖成环会被检测。

## 十一、收藏服务器与服务器面板

1. 左侧导航 **收藏服务器** → 添加服务器（地址 / 端口 / 查询端口）。
2. 列表里看状态与玩家数；对某台服务器打开「面板详情」。
3. 在面板详情顶部选择 **刷新状态 / 地图 / RCON / 打开面板**。
4. 「打开面板」后可改难度、管理地图、上传地图文件、发送 RCON 指令、热重载地图，并跟踪上传任务。

支持收藏 / 最近列表、导入导出服务器清单、一键连接。详见 [收藏服务器](/features/servers)。

## 十二、工具箱 8 件套

左侧导航 **工具箱**：

1. **问题 Mod 查找**（二分法）
2. **Mod 冲突检测**
3. **Mod 模型面数检测**（LOD0 顶点 / 三角面）
4. **崩溃转储查看器**（`.mdmp` / `.dmp`）
5. **喷漆制作**（图片 / 序列帧 → VTF/VMT，可导入到 addons）
6. **autoexec.cfg 编辑器**（命令含义 / 风险 / 来源，保留原编码与换行）
7. **VPK 解包 / VPK 打包**（按内部目录结构拆包；把资源目录打包成 VPK）
8. **VPK 完整性检测**（校验目录、校验和与 `addoninfo.txt`，可安全修复并另存）
9. **压缩包管理**（ZIP / RAR / 7Z / TAR 里识别 VPK 并与现有 Mod 对比）

详见 [工具箱总览](/toolbox/)。

## 十五、数据与安全（平时不用管，知道有就行）

- `addonlist.txt`：快照备份 / 手动备份 / 恢复 / 删除 + 运行时保护；编码、BOM、换行保真；原子写 + 事务回滚。
- 本地记录（`profiles.json` / `groups.json` / `dependencies.json` / `ignore.json` / `priority.json`）：
  备份轮转（最短间隔 + 内容相同跳过 + 数量上限 + 溢出进回收站），带 `schemaVersion` 自动迁移。
- 路径守卫：删除 / 移动 / 改名的**源文件**必须在 addons / workshop / disabled 内；"移动到自选目录"仍允许。
- 文件操作互斥：移动 / 删除 / 打包同一时间只允许一个；失败原因逐项列出。
- 更新源固定本 Fork 的 Release，不回退到上游；发布包附带源码与许可说明。
