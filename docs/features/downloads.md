# 下载与解析

“下载与解析”页面用于把创意工坊链接、合集链接或直链转换为下载任务。

## 解析工坊链接

在输入框中粘贴 Steam 创意工坊链接或工坊 ID，点击解析。

支持的常见输入包括：

```text
https://steamcommunity.com/sharedfiles/filedetails/?id=123456
123456
```

解析成功后会显示标题、作者、文件名、大小和预览图。

## 合集下载

### 把合集保存成"工坊合集"记录

浏览界面里的合集下载是"一次性"的。如果你希望长期跟随某个合集，可以在
“设置 → 工坊数据 → 工坊合集”里粘贴合集链接或合集 ID 并保存：

- 保存时会解析并记录合集的**全部可下载成员**（含嵌套子合集展开的结果），
  本地已经下载过的成员会标记为"已下载"。
- **检查更新**：重新解析合集，列出新增与下架的成员，并刷新本地记录。
- **下载缺失成员**：把本地还没有的成员一次性加入下载队列（已存在的不重复下载）。
- **删除记录**：只删除本地记录，不会删除已经下载的 Mod 文件。

合集记录保存在配置目录的 `collections.json`。

如果输入的是合集，应用会按组展示主物品和子物品。

你可以选择：

- 下载单个文件。
- 下载本组。
- 全部下载。
- 复制下载链接。

不可下载的物品会显示为不可用。

## 直链下载

如果你已经有文件直链，也可以直接填入下载链接并创建任务。

直链下载适合处理不是来自工坊解析结果的 VPK 文件。

需要注意的是，优选 IP 只会加速来自 Steam 创意工坊物品的 Steam CDN 下载链接。普通网站、网盘或其他第三方直链不会因为填写到这里就自动获得加速。

## 下载方式

下载任务会尽量使用多线程分块下载来保证较高的下载速度。应用会根据文件大小自动选择线程数；如果目标服务器不支持分块下载，会自动回退到普通单线程下载。

对于创意工坊文件和来自工坊物品的 Steam CDN 直链，开启优选 IP 后，下载连接也会经过 IP 优选。

## 下载队列

下载任务会进入后台队列。队列中可以查看：

- 当前状态。
- 下载进度。
- 文件大小。
- 速度和错误信息。

失败或取消的任务可以重试。已完成任务可以清理。

### 暂停与继续（断点续传）

下载中的任务可以**暂停**，之后**继续**时会**接着下**，而不是从头再来：

- 暂停会保留已经下好的部分（大文件按 5MB 区块记录"哪些块已经完整拿到"）；
- 继续时只补没下完的区块 —— 已经下好的部分不会重复下载；
- **关掉应用再打开也没关系**：暂停中的任务会以「已暂停」保留，点「继续」就能接着下；
- 下载失败时同样保留已下载的部分，点「重试」直接从断点继续；只有点「取消」才会丢弃这些临时数据；
- 小文件走的是单线程下载，没有分块信息，所以暂停后继续会重新下这个小文件（几 MB，代价可以忽略）。

临时数据放在游戏目录的 `temp/` 下，超过 7 天没动过的残留会在启动时自动清理。

队列里的任务状态包括：`等待中` / `优选线路中` / `下载中` / `已完成` / `失败` / `已取消` / **`已中断`**。

### 重启后还能看到上次没下完的任务

下载进度会**最多每秒写一次**到 `download_tasks.json`（内容与上一份相同则跳过写入），
所以应用退出时不会把进度全部丢掉：

- 重新打开应用后，上次没下完的任务会以 **`已中断`** 出现在队列里，并保留已经下载的字节数；
- 中断的任务不会自动重新开始（避免一开就抢带宽），点一次「重试」即可继续；
- 「清理已完成」会一并清掉中断的任务；中断任务同样可以单独开关「失败后自动重下」。

### 同一个 Mod 不会重复排队

如果同一件工坊作品（或同一个直链目标文件）已经在队列里且还没结束，
再次点下载会**直接复用已经排好的那个任务**，不会出现两条并行下载同一个文件。

顺带一提，「检查更新」也做了同样的去重：如果一次检查还在跑，再点一次不会并发开跑第二遍，
而是等这次的结果复用（避免成倍消耗工坊接口配额）。

### 检测期间把 Mod 移走 / 换掉会怎样

「检查更新」是逐个 Mod 去查工坊的，查完一个写一个。如果**在它还在查的时候**你把某个 Mod
移进了 `disabled`、改了文件名，或者用另一个文件把它换掉了，那么这次查到的结果就不属于
现在这个文件了 —— 应用会**直接放弃写入**，而不是把时间戳塞回一个已经不在原处的路径
（那样会留下一个谁也看不懂的孤立 `.meta`）。

这类被跳过的数量记在检查结果里（`skipped_stale`），日志里也会写一行
「检测到更新，但目标已被移动或替换，跳过写入」。移动之后再点一次「检查更新」就会按新位置重新算。

## 优选 IP 加速

开启“优选 IP 加速”后，应用会为 Steam CDN 选择更合适的线路，用于提升创意工坊图片和工坊文件下载体验。

如果正在优选线路，下载按钮会等待优选完成后继续。网络较差时可以关闭加速，或改用手动固定 IP。

## 常见问题

### 工坊解析失败怎么办？

创意工坊解析依赖外部网络。可以尝试：

- 重新解析工坊链接或工坊 ID。
- 检查网络正常。
- 稍后重试。
- 提交问题反馈。

### 下载任务失败怎么办？

先查看下载队列里的错误信息。常见处理方式：

- 点重试。
- 检查优选 IP 是否开启。
- 复制直链到浏览器确认链接是否还能访问。

## 下载失败自动重下

该功能**默认关闭**。开启后，新建的下载任务在失败时会自动重试一次：

- 在“设置 → 工坊数据”里打开“下载失败后自动重下一次”，之后的下载任务默认带上该策略。
- 也可以在下载队列里单独开关某个任务。
- 用户主动取消的任务不会被自动重下覆盖。
- 自动重试只做一次；第二次仍然失败时，任务保持失败状态并保留错误信息，等待你手动处理。
