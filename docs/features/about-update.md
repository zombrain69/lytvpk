# 关于与更新

“关于”页面展示应用信息、项目链接和版本更新入口。

## 项目信息

关于页会显示：

- 作者。
- 开源协议。
- GitHub 仓库。
- 问题反馈入口。
- 当前版本。

项目仓库地址为：

```text
https://github.com/zombrain69/lytvpk
```

本 Fork 基于上游项目 [LaoYutang/lytvpk](https://github.com/LaoYutang/lytvpk)。上游链接仅用于署名和追溯，不作为本 Fork 的更新源。

## 检查更新

点击“检查更新”后，应用会请求最新版本信息。

如果发现新版本，会显示：

- 当前版本。
- 最新版本。
- 更新内容。
- 下载镜像选择。

## 下载镜像

更新弹窗支持 GitHub 直连和镜像地址。可以刷新镜像延迟，也可以填写自定义镜像。

如果下载很慢或失败，可以换一个镜像再试。

## 更新注意事项

- 更新时不要手动删除正在运行的程序文件。
- 如果杀毒软件拦截下载或替换，请先确认来源再放行。
- 更新完成后应用会重启。

## 常见问题

### 更新失败怎么办？

可以尝试：

- 更换下载镜像源。
- 关闭应用后重新启动再检查更新。
- 检查是否有杀毒软件拦截。
- 手动下载新版覆盖安装。
## 崩溃报告（只保存在本机）

应用会捕获**自己**的异常并写成一份本地报告，方便反馈问题时说清原因：

- 捕获范围：后端后台任务（扫描 / 下载 / 冲突检测）里的 panic、启动流程里的 panic、
  以及前端的未处理异常与未处理的 Promise 拒绝。
- 报告位置：配置目录下的 `crashes/`。点“关于 → 崩溃报告 → 打开崩溃报告目录”即可打开。
- 报告内容：时间、应用版本、Go 版本、操作系统与架构、错误原因、堆栈、最近的日志尾部。
- 只保存在本机，**不会联网上传**；报告数量最多保留 30 份，旧的自动清理。
- 游戏或 Windows 的原生崩溃转储（`.mdmp` / `.dmp`）请继续用
  “工具箱 → 崩溃转储查看器”打开，两者互补。
