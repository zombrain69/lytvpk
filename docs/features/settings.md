# 设置

“设置”页面分为网络设置、界面设置和工坊设置。

## 网络设置

网络加速用于创意工坊图片和文件下载。

可选模式：

- 自动优选最佳 IP：应用自动选择推荐线路。
- 手动指定 IP：从候选列表选择，或填写自建加速 IP。

如果当前网络访问 Steam CDN 正常，可以保持默认；如果图片加载慢或下载慢，可以尝试开启。

## 界面设置

### 窗口：浮动 / 停靠

复杂的管理窗口（Mod 详情、加载顺序、冲突检测、策略组管理、智能体提示词、标签编辑、加入分组、
服务器面板各窗口、问题 Mod 查找… 共 19 个）都支持浮动：

- 标题栏右侧有「**浮动窗口 / 停靠窗口**」按钮：浮动后**背景不再虚化**，可以直接操作主界面；
- 浮动窗口可以**拖动标题栏移动**、**拖动边缘缩放**，位置与大小按窗口分别记住；
- **双击标题栏** = 重置这个窗口记住的位置与大小（窗口被拖到屏幕外时的逃生口）；
- 窗口尺寸会被限制在可视区内（最大 96% × 94%），换到小屏也不会出现"标题栏跑到屏幕外"。

确认 / 输入 / 重命名 / 退出确认这类**小对话框刻意保持居中模态**（避免误触）；
创意工坊、下载、收藏服务器这三个是**独立页面**（不是弹窗），所以没有浮动概念。

### 命令面板（Ctrl+K）

按 **Ctrl+K** 打开命令面板，一句话找到任何功能或页面：

- 也可以直接点**标题栏的搜索图标**打开（不必记快捷键）；
- 直接输入关键词：`冲突`、`体检`、`工坊`、`字号`、`mdmp`…（标题优先，关键字兜底）；
- **↑↓** 选择、**Enter** 执行、**Esc** 关闭；也可以直接点某一条；
- 覆盖 7 个页面 + 常用动作：搜索 Mod、策略组管理、分组建议、加载顺序优化、冲突分析开关、开始体检、
  抓取工坊官方标签与统计、界面设置、切换主题，以及 **重置所有窗口的位置与大小**；
- 面板底部在没输入关键词时会列出全局快捷键（`Ctrl+K` 命令面板 / `Ctrl+F` 搜索 / `Ctrl+±`、`Ctrl+0` 缩放）。
- **最近用过的最多 5 条会排在最上面**，并标上「最近 ·」；记录存在本地
  （`lytvpk.commandPalette.recent`），清掉浏览器数据即重置，不影响其它设置。
- 命令面板里还有一条「查看键盘快捷键」，和标题栏的 **`?`** 按钮打开的是同一个浮层
  （也可以直接按 `?` 键；光标在输入框里时不会抢键）。

### 键盘快捷键总览（`?`）

标题栏最右侧的 **`?`**（或直接按 `?`）打开快捷键总览，分三组列出全部键位：

| 分组 | 键位 |
| --- | --- |
| 全局 | `Ctrl+K` 命令面板 · `Ctrl+F` 聚焦搜索 · `Ctrl + =` / `Ctrl + -` 界面缩放 · `Ctrl+0` 回到 100% · `?` 本总览 |
| 搜索框里 | `↑` / `↓` 移动光标 · `Enter` 打开详情 · `Esc` 清空搜索 |
| 窗口与浮层 | `Esc` 关闭（点窗口外同样可以） · 双击标题栏复位该窗口的位置与大小 |

这份表由 `frontend/src/js/core/shortcuts.mjs` 单点维护：搜索语法说明书里的快捷键段、
命令面板入口、标题栏浮层都从它生成，改一处即可；测试还会核对"表里写的键位在代码里真的有绑定"。

`↑` / `↓` / `Enter` / `Esc` 这一组在**所有带搜索框的列表**里通用：
Mod 列表（详情）、压缩包管理（展开压缩包）、模型统计（展开模型行）都是同一套手感，
光标位置会显示在计数后面（例如 `匹配 2 / 7 个压缩包 · 第 1 / 7 个结果（Enter 展开 / 收起）`）。

窗口被拖到屏幕外、或拉得比屏幕还大时，用命令面板里的「**重置所有窗口的位置与大小**」一键复位
（等价于清掉这些窗口记住的几何；下次打开就是默认位置）。

### 正在处理文件时的提示

移动 / 删除 / 打包是互斥的（同一时间只允许一个）。有操作在跑时：

- 状态栏显示「**正在处理文件（移动 / 删除 / 打包）… 完成后可继续**」；
- 会写磁盘的批量按钮变灰，避免点了才拿到"另一个文件操作正在进行"的报错。

这个状态由后端主动推事件，毫秒级跟上；即使是很小的打包（不到 1 秒）也不会漏掉提示。

### 文字大小与阅读舒适度

「界面缩放」和「文字大小」是两件不同的事，可以叠加使用：

| 设置 | 影响范围 | 什么时候用 |
| --- | --- | --- |
| 界面缩放 | 整体缩放（文字、间距、图标一起变大） | 屏幕尺寸差异大、想整体放大或缩小 |
| 文字大小（紧凑 / 标准 / 大 / 特大） | **只改文字**，不动布局 | 2K / 4K 屏上字太小、又不想让整个界面占满屏 |

两者相乘生效：根字号 = 界面缩放 × 文字档位（例如界面缩放 110% × 文字「大」112% ≈ 123%）。
快捷键仍然是 `Ctrl +` / `Ctrl -` / `Ctrl 0`（管界面缩放）。

「阅读舒适度」调整的是**行距与文字对比度**，用来解决"看久了累"：

- **柔和**：行距更松（1.8）、正文对比度更柔和 —— 长时间翻列表更省眼；
- **标准**：默认的对比度与行距（1.65）；
- **高对比**：行距更紧（1.55），**只把正文与次要文字提上去**（明亮主题更深、暗色主题更亮），
  计数、提示、搜索 chip 这类装饰性文字保持标准档的弱化程度 ——
  否则满屏都是"重点"，读长列表反而更累。这条不变量由
  `frontend/src/js/core/reading-contrast-css.test.mjs` 用相对亮度守着。

两个设置都写在 `config.json`（`textSize` / `readingComfort`），下次启动自动恢复；
手改配置写了不认识的值会回落到「标准」。

界面设置用于调整 MOD 管理页的使用习惯。

- 显示模式：列表或卡片。
- 框选模式：拖拽绘制选择框来批量选择文件。
- Ctrl+单击选择：按住 Ctrl 点选多个 Mod。
- 筛选布局：简洁模式节省空间，经典模式展开更多筛选项。

## 工坊数据

“开启工坊信息存储”会为工坊文件创建 `.meta` 信息，用于保存名称、作者等数据。

开启后可以使用 Mod 更新检测。更新检测会检查带有工坊信息的 Mod 是否存在新版本。

### 剪贴板工坊链接自动识别

默认开启。复制一条创意工坊链接（或直接复制作品 ID）后切回 LytVPK，会弹一个确认框问是否打开下载页并解析该作品，
省去"手动粘贴 + 点检查"两步。窗口不在前台时不会读取剪贴板；读完同一条链接不会反复打扰。
不想要这个提示就在「设置 → 工坊数据」里关掉。

## 打开文件方式（界面设置）

「界面设置」最下面的「打开文件方式（可选）」决定你点 Mod 菜单里的**打开所在位置**时用哪个程序：

| 字段 | 留空时 | 填了之后 |
| --- | --- | --- |
| 程序 | 用系统默认（Windows 用资源管理器定位并选中该文件，行为与以前一模一样） | 用你填的程序；只填命令名（如 `code`）会交给 PATH 查找，填路径则要求文件真实存在 |
| 参数模板 | 把文件完整路径作为唯一参数 | 按模板拼参数，支持 `{path}`（完整路径）、`{dir}`（所在目录）、`{name}`（文件名），也兼容 `{0}` = 完整路径；模板里一个占位符都不写时，会自动把完整路径追加到末尾 |

常见写法：

- 用 Total Commander 定位：程序 `C:\Tools\totalcmd\TOTALCMD64.EXE`，参数 `/O /T /L="{dir}"`
- 用 VPK 编辑器打开文件：程序 `C:\Tools\VPKEdit\vpkeditcli.exe`（举例），参数 `"{path}"`
- 用 VS Code 打开所在工程目录：程序 `code`，参数 `"{dir}"`

参数里有空格就用双引号包住。保存时会校验：带路径的程序如果不存在会直接报错（避免填错还不自知）；
点「恢复默认」即清空两项，回到系统默认。程序与参数不会经过命令行解释器，直接启动。

### 抓取工坊官方标签与统计

这一栏的「**抓取工坊官方标签与统计**」按钮会去 Steam 官方接口
（`ISteamRemoteStorage/GetPublishedFileDetails`）补取每个工坊 Mod 的：

- **官方标签**：作者/玩家在工坊上填的分类，例如 `Survivors`、`Sounds`、`Single Player`、`Campaigns`。
  它们会写进同名 `.meta` 的 `steam_tags`，**不会覆盖**你在 LytVPK 里自己整理的标签（`tags` / 一级标签 / 子标签）。
- **官方热度**：订阅数、收藏数、浏览量。

抓过之后：

- 「分组 → 准备给智能体材料」导出的清单里会多出 `workshop.steamTags` 与热度数字，
  分组建议与自动标签会准得多（智能体的提示词里已经写明"判断类型时优先信官方标签"）；
- 每个 Mod 只补自己的 `.meta`：**不动 Mod 文件、不动 `addonlist.txt`**，随时可以再抓一遍（相同数据不会重复写盘）。

几点说明：

- 只对 `workshop` 目录下、能对上 `<工坊ID>.vpk` 的 Mod 生效；本地自制 Mod 没有工坊资料，会跳过。
- 需要能访问 Steam 官方接口。国内网络下如果一直"官方接口没返回 N 个"，可以给应用配上代理
  （应用会读取系统代理环境变量），或者只在需要做分组建议前抓一次。
- 提示里的四个数字分别是：更新了几个、本来就最新几个、本地没有文件几个（一般是已退订）、接口没返回几个。

## 工坊浏览器跳转

“跳转目标”决定在工坊详情里点击“使用浏览器打开”时打开哪里：

- 镜像站 `l4d2ws.com`。
- Steam 官方工坊。

## 描述翻译

描述翻译用于创意工坊详情页。支持：

- 微软。
- Yandex。
- 自定义 AI。

使用自定义 AI 时，需要填写 Base URL、API Key 和模型 ID。

## 本地记录备份

启用方案、策略组、Mod 依赖、单 Mod 忽略清单与优先级分层这些**本地记录**在每次写入前
会自动轮转备份，规则与应用内其它备份保持一致：

- 备份位置：配置目录下的 `backups` 文件夹，文件名形如
  `profiles.backup_2026-09-22_10-00.json`。
- 最短间隔 15 分钟：刚备份过就不会重复备份。
- 内容去重：如果当前内容与最近一份备份完全相同，不会产生新的备份文件。
- 只保留最近 10 份；超出上限的旧备份会**移入回收站**，仍可从回收站恢复。

这些备份只包含本地记录（不包含 VPK 文件与 `addonlist.txt` 的历史），
`addonlist.txt` 的备份在“历史备份”面板里单独管理。
